# Decisão — metas por vendedora

## Status
Aprovada para implementação técnica sem presumir periodicidade.

## Decisão
Cada meta é definida por:
- vendedora;
- métrica (`REVENUE`, `SALES` ou `CLIENTS`);
- valor-alvo;
- início;
- fim;
- observação opcional.

O ERP não cria recorrência automática por mês/semana/dia porque essa periodicidade não está definida no documento-fonte.

O realizado considera apenas vendas com estágio `PAID`, preservando a mesma base factual já usada nos relatórios comerciais.

## Fora desta decisão
- fórmula de comissão;
- percentual de comissão;
- competência/comissionamento;
- treinamento/desenvolvimento como workflow próprio.
